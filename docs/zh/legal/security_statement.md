# **msMemScope 安全声明**

请在使用工具前，仔细阅读以下安全使用声明，以防范潜在风险。msMemScope为开发调测工具，不应在生产环境中使用。

## 系统安全加固

- 本仓提供VS Code及devcontainer配置，便于开发和调试；仅限在安全的调试环境中对本仓进行开发和调试使用。请自行检查配置安全性，并根据实际需求进行调整。
- 请对下载的msMemScope安装包及相关文件使用SHA256等校验方法进行完整性校验，保证文件来源安全可信，从而有效避免潜在的安全风险。

## 运行用户建议

出于安全性及权限最小化考虑，不建议使用root等管理员类型账户安装、运行msMemScope，推荐使用普通用户权限。使用root用户运行时，工具会打印提示并跳过文件权限校验，存在安全风险。

## 文件权限控制

- 遵循最小权限原则（如禁止others用户可写，常见如禁止666、777）。
- 请确保执行用户的umask值大于等于0027，否则会导致获取的性能数据所在目录和文件权限过高。
- 用户提供输入信息时应保障内容安全可信，避免出现符号链接，任何文件均应转换为真实绝对路径后输入，以防止可能出现的安全问题。

## 数据安全

msMemScope在采集与分析过程中会在输出目录（默认memscopeDumpResults）生成性能数据文件，包括内存事件记录、Python/C调用栈、内存快照等；开启内存块监测full-content时，还会落盘完整Tensor数据；Host堆内存泄漏检测会生成泄漏概览与内存块明细文件。上述文件可能包含用户代码调用栈、业务数据内容等敏感信息，请关注输出目录的权限控制，使用完毕后及时清理或妥善保管。

## 运行安全

msMemScope在运行异常时会退出进程并打印报错信息，建议根据报错提示定位具体错误原因；工具日志会落盘至输出目录的msmemscope_logs子目录，可供问题定位参考。

## 公网地址

不涉及。msMemScope所有功能均在本机执行，不访问任何公网地址。

## 公开接口

msMemScope对外公开Python接口与命令行参数：Python接口包括采集控制、内存快照采集、自定义Trace打点、离线内存分析（analyze、check_leaks、check_inefficient等）；命令行支持内存采集、内存对比、进程外控制通道等参数。所有接口均在本机执行，不涉及网络传输。具体请参见《[API参考](../api_reference/api.md)》与《[内存采集](../user_guide/memory_profile.md)》。

## 通信矩阵

msMemScope不涉及网络通信。唯一的进程间通信为进程外控制通道（动态附加）功能，通信范围仅限本机，如下表所示。

| 通信类型 | 通信协议/方式 | 通信对端 | Socket/端口 | 用途 | 备注 |
| -------- | ------------- | -------- | ----------- | ---- | ---- |
| 本机进程间通信 | Unix域socket | msmemscope控制端与目标进程 | `/tmp/msmemscope_socket_<PID>` | 下发启停、巡检、配置查看/修改等控制字 | socket文件仅在握手期存在，目标进程注册成功后即删除 |
